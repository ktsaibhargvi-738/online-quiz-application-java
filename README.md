# Online Quiz Application using Java

## 📌 Project Description

The Online Quiz Application is a simple Java-based project that allows users to answer multiple-choice questions and calculates their final score.

## ✨ Features

* Multiple-choice questions
* User can select an answer
* Automatic score calculation
* Displays the final score
* Simple and beginner-friendly Java program

## 🛠️ Technologies Used

* Java
* Scanner class

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in any Java IDE.
3. Compile the program:

```bash
javac OnlineQuiz.java
```

4. Run the program:

```bash
java OnlineQuiz
```

5. Select the correct option for each question.
6. Your final score will be displayed.
